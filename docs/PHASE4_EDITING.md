# NanoCorona — Phase 4 controlled editing

## Flow

Corona passes + Scene.json + MAXScript preset + user prompt → Edit.json → NanoNetwork.dll → Gemini → result

The Edit.json file is an internal control representation. Gemini receives a provider-specific prompt containing the plan and scene context; it is not expected to execute arbitrary JSON as a command language.

## Presets

| Preset | Target | Operation | Protected intent |
|---|---|---|---|
| Photorealism | overall appearance | modify | architecture/camera preserved |
| Change Sky | sky | replace | building silhouette/facade preserved |
| Weather | environment | modify | architecture preserved |
| Materials | architectural materials | modify | material boundaries/geometry preserved |
| Wet Road | road and pavement | modify | architecture/camera preserved |

The user prompt remains editable after selecting a preset. The preset supplies a structured baseline operation; the prompt supplies the free-form refinement.

## Edit.json contract

Each generated plan contains schemaVersion, preset, source, operations[], and globalConstraints[]. Each operation has an action, target, instruction, strength, protected flag, appearance-only flag, and mask hint.

## Controlled editing rules

1. Beauty is the primary visual reference.
2. Z-Depth and normals are spatial/control references.
3. Architecture mask is passed as a separate reference image.
4. When Architecture locked is enabled, Edit.json records the protection and the provider prompt explicitly states that the mask is authoritative.
5. Camera composition, facade layout, window placement and structural geometry are constrained by default.
6. The edit is intended to be appearance-focused; structural edits are not generated by these presets.

## Validation status

The code path is implemented, but no live 3ds Max/Corona runtime test was performed in this environment. The remaining Phase 4 research task is the A/B benchmark of reference-pass combinations plus environment-mask experiments.
